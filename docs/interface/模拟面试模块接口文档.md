# 模拟面试模块接口文档

**版本**：v0.1  
**基础路径**：`/api/v1`  
**Content-Type**：`application/json`  
**认证**：先调用 `POST /api/v1/auth/login`，后续带 `Authorization: Bearer <accessToken>`；登录/刷新/登出见 [登录认证接口文档](./登录认证接口文档.md)。

> 本模块是“模拟卷 / 刷题”模式：一次生成整卷、逐题保存答案、批量评估；不做对话式追问。模块设计见 [模拟面试模块说明文档](../req/模拟面试模块说明文档.md)。

---

## 通用约定

### 统一响应体

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

### 异步任务约定

- 发起面试、提交评估返回 HTTP **202 Accepted**；
- 响应 body 仍为统一响应体，`code=200`；
- 前端通过 `GET /api/v1/interviews/{sessionId}` 轮询；
- 建议轮询间隔 2 秒，响应头返回 `Retry-After: 2`；
- 出题/评估失败返回 `status=4`，可重试。

### 会话状态

| status | 含义 |
|---|---|
| 0 | 生成中 GENERATING |
| 1 | 待作答 READY |
| 2 | 评估中 EVALUATING |
| 3 | 已完成 FINISHED |
| 4 | 失败 FAILED |

### 答案状态

- `interview_answers` 以 `(sessionId, questionIndex)` 唯一；
- 重复保存覆盖；
- 未作答的题在评估时按 0 分处理。

## 1. 发起模拟面试

`POST /api/v1/interviews`

**请求体**

```json
{
  "directionTagIds": [106, 107, 109],
  "jobId": 3,
  "resumeId": 12,
  "jdText": "负责内容矩阵运营，要求数据复盘与 A/B 测试经验……",
  "difficulty": "intermediate",
  "questionCount": 5,
  "followUpCount": 1
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| directionTagIds | long[] | 否 | 技能方向标签 ID，1–6 个，必须 `tags.category='skill'` |
| jobId | long | 否 | 目标岗位；未传方向时从 `job_tags` 推导方向 |
| resumeId | long | 否 | 简历 ID；有则生成简历题 |
| jdText | string | 否 | 额外 JD 文本；jobId 已带 JD 时可省略 |
| difficulty | string | 是 | `basic` / `intermediate` / `advanced` |
| questionCount | int | 是 | 主问题数量，3–15 |
| followUpCount | int | 是 | 每个主问题追问数，0–3 |

**方向解析规则**

1. `directionTagIds` 非空：按传入顺序，最多 6 个，校验 `category='skill'`。
2. 否则 `jobId`：取岗位 `job_tags` 中 skill 标签，`weight=1.0` 优先。
3. 否则取 `user_skill_profile` 中 level 最高的前 3–5 个 skill 标签。
4. 仍为空：使用“通用职业能力”兜底。

> `skill.meta.yml` 是可选配置，只影响 label/priority/参考题库；没有它也能按 tags 出题。

**响应**：HTTP 202

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "sessionId": 21,
    "status": 0,
    "statusText": "GENERATING"
  }
}
```

**错误**

| code | 场景 |
|---|---|
| 40005 | 题量/追问数/难度非法 |
| 40007 | 方向标签非法（不是 skill） |
| 40402 | 岗位不存在 |
| 40404 | 简历不存在 |
| 50005 | 出题失败（轮询后 status=4） |

## 2. 分页查询会话

`GET /api/v1/interviews`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| page | int | 否 | 页码 |

## 4. 保存单题答案

`PUT /api/v1/interviews/{sessionId}/answers/{questionIndex}`

**请求体**

```json
{
  "answerText": "我先按用户画像拆选题，再用历史数据筛掉低效方向……"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| answerText | string | 是 | 答案，最大 5000 字 |

**响应**：HTTP 200

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "sessionId": 21,
    "questionIndex": 0,
    "answerText": "我先按用户画像拆选题……",
    "answeredAt": "2026-11-13 20:10:00"
  }
}
```

**说明**

- 仅 `status=1 READY` 可保存；
- `questionIndex` 必须存在；
- 重复保存同一题覆盖，不产生重复行；
- 空字符串表示清空答案（是否允许清空由实现决定，建议允许）。

**错误**

| code | 场景 |
|---|---|
| 40405 | 会话不存在 |
| 40903 | 当前状态不能作答 |
| 40006 | 题号不存在 |
| 40008 | 答案超长 |

## 6. 提交评估

`POST /api/v1/interviews/{sessionId}/evaluate`

**请求体**：无（使用已保存的答案）

**响应**：HTTP 202

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "sessionId": 21,
    "status": 2,
    "statusText": "EVALUATING"
  }
}
```

**说明**

- 仅 `status=1 READY` 可提交；
- 至少有一道题已保存答案；
- 未作答的题按 0 分处理；
- 评估异步执行，前端轮询详情；
- 重复提交返回 `40904`；
- 评估完成后 `status=3 FINISHED`，详情返回报告。

**错误**

| code | 场景 |
|---|---|
| 40405 | 会话不存在 |
| 40904 | 正在评估中 |
| 40903 | 当前状态不能评估 |
| 40009 | 没有可评估的答案 |

## 7. 查询记忆候选

`GET /api/v1/interviews/{sessionId}/memory-candidates`

仅 `status=3 FINISHED` 可查。

**响应**：HTTP 200

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "sessionId": 21,
    "candidates": [
      {
        "candidateId": 101,
        "tagId": 106,
        "tagName": "内容策划",
        "content": "模拟面试：能按用户画像拆解内容选题，并说明数据不达预期时的调整思路。",
        "proficiency": 3,
        "confidence": 0.86,
        "evidence": "先按用户画像拆选题，再用阅读完成率复盘……",
        "status": 0
      }
    ]
  }
}
```

**说明**

- 只有维度分 ≥ 60 的 skill 才生成候选；
- `status`：0 待确认、1 已确认、2 已忽略；
- 低分/缺口只进报告，不生成候选；
- 未确认不写 `memory_items`。

**错误**

| code | 场景 |
|---|---|
| 40405 | 会话不存在 |
| 40908 | 会话尚未完成评估 |

## 8. 确认写入职业记忆

`POST /api/v1/interviews/{sessionId}/confirm-memories`

**请求体**

```json
{
  "candidateIds": [101, 102]
}
```

**响应**：HTTP 200

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "sessionId": 21,
    "imported": 2,
    "skipped": 0,
    "memoryIds": [301, 302]
  }
}
```

**写入规则**

1. 候选必须属于该会话且 `status=0`；
2. 每条候选写一条 `memory_items`：
   - `source_type='interview'`；
   - `source_id=sessionId`；
   - `status=1`；
3. 写 `memory_tags`：
   - `tag_id` = 候选 tag；
   - `polarity=1`；
   - `proficiency/confidence/evidence` 取候选；
   - `assessed_by='manual'`（用户确认）；
4. 更新候选 `status=1`、`memory_id`；
5. 触发 `user_skill_profile` 异步重算；
6. 重复确认同一候选幂等。

**错误**

| code | 场景 |
|---|---|
| 40405 | 会话不存在 |
| 40406 | 候选不存在 |
| 40908 | 会话尚未完成评估 |
| 40909 | 候选已处理 |

## 错误码汇总

| code | 场景 | 建议提示 |
|---|---|---|
| 40005 | 题量/追问数/难度非法 | 题量或难度参数非法 |
| 40006 | 题号不存在 | 答案与题目不匹配 |
| 40007 | 方向标签非法 | 请选择有效的技能方向 |
| 40008 | 答案超长 | 单题答案不能超过 5000 字 |
| 40009 | 没有可评估答案 | 请至少作答一道题 |
| 40405 | 会话不存在 | 面试会话不存在 |
| 40406 | 记忆候选不存在 | 候选不存在或已处理 |
| 40903 | 状态不允许 | 当前状态不能执行该操作 |
| 40904 | 正在处理中 | 正在处理中，请稍候 |
| 40908 | 尚未完成评估 | 请等待评估完成 |
| 40909 | 候选已处理 | 该候选已确认或忽略 |
| 50005 | 出题失败 | 出题服务暂时不可用 |
| 50006 | 评估失败 | 评估服务暂时不可用 |

## 轮询示例

```text
POST /api/v1/interviews                         → 202 { sessionId:21, status:0 }
GET  /api/v1/interviews/21                      → 200 { status:0 }
GET  /api/v1/interviews/21                      → 200 { status:1, questions:[...] }
PUT  /api/v1/interviews/21/answers/0            → 200
PUT  /api/v1/interviews/21/answers/1            → 200
GET  /api/v1/interviews/21/answers              → 200
POST /api/v1/interviews/21/evaluate             → 202 { status:2 }
GET  /api/v1/interviews/21                      → 200 { status:2 }
GET  /api/v1/interviews/21                      → 200 { status:3, report:{ totalScore:78, ... } }
GET  /api/v1/interviews/21/memory-candidates    → 200 [...]
POST /api/v1/interviews/21/confirm-memories     → 200 { imported:2 }
```
