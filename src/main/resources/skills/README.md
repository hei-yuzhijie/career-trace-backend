# 技术岗题库（可选参考）

本目录存放面试出题时可注入的参考题库，方向主数据仍是数据库 `tags.category='skill'`。  
`InterviewReferenceService` 会按 tag 的 slug/name 匹配以下文件，拼接到 `{referenceSection}`。

| tag slug / name | 参考文件 |
|---|---|
| `java` / Java | `skills/java-backend/references/java.md` |
| `mysql` / MySQL | `skills/java-backend/references/mysql.md` |
| `redis` / Redis | `skills/java-backend/references/redis.md` |
| `spring` / Spring | `skills/java-backend/references/spring.md` |
| `ai_agent` / AI Agent / Agent | `skills/ai-agent-dev/references/agent.md` |
| `system_design` / 系统设计 | `skills/system-design/references/system-design.md` |
| `algorithm` / 算法 | `skills/algorithm/references/algorithm.md` |
| `frontend` / 前端 | `skills/frontend/references/frontend.md` |

参考题库只用于校准考点和追问方向，不是逐字照搬的标准答案；最终题目必须结合候选人证据、岗位 JD 和难度。
