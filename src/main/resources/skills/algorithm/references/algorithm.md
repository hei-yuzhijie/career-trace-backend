# 算法与数据结构参考题库

## 基础
- 数组/链表/栈/队列/哈希表/堆/树的适用场景与复杂度。
- 排序：快排、归并、堆排的稳定性、最坏复杂度、工程选择。
- 二分：边界、循环不变量、旋转数组、答案二分。

## 高频题型
- 双指针、滑动窗口、前缀和、差分。
- 二叉树遍历/递归/层序、BST 性质。
- 图：BFS/DFS、拓扑排序、并查集、最短路。
- 动态规划：状态定义、转移、初始化、空间优化。
- 回溯与剪枝；贪心的正确性证明。

## 出题模板
- 先讲思路和复杂度，再写代码；边界条件怎么处理？
- 这个题能否从 O(n²) 优化到 O(n log n)？依据是什么？
- 如果数据量到 1 亿/内存受限，方案怎么变？
- 如何证明你的贪心/DP 是正确的？
