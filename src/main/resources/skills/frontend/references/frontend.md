# 前端工程参考题库

## JavaScript
- 原型链、闭包、`this`、事件循环、微任务/宏任务。
- Promise/async-await、错误处理、并发控制。
- 模块化、Tree Shaking、包体积治理。

## React / Vue
- 组件生命周期/副作用、状态管理、不可变数据。
- 虚拟 DOM、diff、key、渲染性能。
- React Hooks 闭包陷阱；Vue 响应式原理。

## 浏览器与性能
- 从输入 URL 到页面展示；缓存、DNS、TCP/TLS。
- 重排/重绘、合成层、懒加载、预加载。
- 核心指标：FCP/LCP/CLS/INP；错误率与包体积。

## 出题模板
- 这个页面为什么卡？如何定位到具体组件/资源？
- 状态管理方案怎么选？边界和代价是什么？
- 首屏指标怎么量化？优化前后如何对比？
- 线上白屏/报错怎么排查和兜底？
