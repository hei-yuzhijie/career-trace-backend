# MySQL 参考题库

## 索引
- B+ 树结构、聚簇索引与二级索引、回表、覆盖索引。
- 最左前缀、索引下推、索引失效场景。
- 联合索引顺序如何设计？区分度与范围查询的取舍。

## 事务与锁
- ACID、隔离级别、MVCC、Read View。
- 快照读与当前读、间隙锁、临键锁、死锁排查。
- 长事务的危害与治理。

## SQL 与优化
- `EXPLAIN` 关键字段：type、key、rows、Extra。
- 深分页优化：延迟关联、游标、覆盖索引。
- 大表 DDL、在线变更、分库分表边界。
- 慢查询定位：慢日志、执行计划、锁等待、Buffer Pool。

## 出题模板
- 这条 SQL 为什么走/不走索引？给出执行计划依据。
- 事务隔离级别如何影响并发读写？举一个幻读场景。
- 数据量从 100 万到 1 亿，存储和查询怎么演进？
- 线上死锁如何复现、定位和治理？
