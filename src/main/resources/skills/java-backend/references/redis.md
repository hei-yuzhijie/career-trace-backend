# Redis 参考题库

## 数据结构与命令
- String/Hash/List/Set/ZSet 的底层编码与适用场景。
- 排行榜、计数器、去重、延迟队列如何选结构。
- 大 key、热 key 的识别与治理。

## 缓存治理
- 缓存穿透、击穿、雪崩的区别与组合方案。
- 旁路缓存、读写一致性、延迟双删、订阅 binlog。
- 逻辑过期与互斥重建的取舍。
- 缓存命中率、TTL 抖动、预热与降级。

## 持久化与高可用
- RDB/AOF、混合持久化、fsync 策略。
- 主从复制、哨兵、Cluster 分片、槽迁移。
- 分布式锁：SETNX、续期、误删、Redlock 争议。

## 出题模板
- 这个业务为什么用 Redis？不用会怎样？
- 缓存与数据库不一致时，你的兜底策略是什么？
- 热 key 打满单节点，怎么发现并拆分？
- Redis 集群扩缩容时，客户端和业务要注意什么？
