# Spring 参考题库

## IoC / AOP
- Bean 生命周期、作用域、循环依赖与三级缓存。
- 自动装配、条件装配、`@Configuration` 代理。
- AOP 代理方式、切点、事务失效场景。

## 事务
- `@Transactional` 传播行为、隔离级别、回滚规则。
- 自调用失效、异常被吞、异步线程事务。
- 大事务拆分与最终一致性。

## Spring Boot / Web
- 启动流程、自动配置、Starter 原理。
- 拦截器、过滤器、参数解析、全局异常。
- 连接池、线程池、超时、重试、幂等。
- 可观测性：日志、指标、链路追踪。

## 出题模板
- 这个 Bean 什么时候初始化？依赖冲突怎么排查？
- 事务为什么没回滚？给出排查路径。
- 接口 P99 变高，如何从 Spring 层定位？
- 你如何设计一个可复用的 Starter？
