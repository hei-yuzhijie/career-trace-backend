# 系统设计参考题库

## 答题框架
1. 澄清约束：QPS、峰值倍数、SLA、数据量、延迟、一致性、成本。
2. 核心链路：请求路径、读写路径、关键状态、失败路径。
3. 工程细节：容量估算、监控告警、降级兜底、回滚补偿。

## 高频场景
- 秒杀：限流削峰、缓存库存、异步下单、幂等、超时回补。
- Feed：推/拉/推拉结合、时间线有序、分页游标、热点用户。
- 短链：短码生成、冲突处理、缓存、统计、过期。
- 延迟任务：Redis ZSet/MQ 延迟消息/时间轮；可靠投递与重复执行。
- 站内消息：未读计数、聚合、已读、离线补偿、幂等。
- 登录风控：失败计数、TTL 锁定、分级验证、防枚举。

## 追问清单
- 为什么这样分层？瓶颈先出在哪里？
- 失败后谁触发补偿？如何防重？
- 峰值翻 3 倍先扩哪个组件？依据是什么？
- 怎么证明方案有效？核心指标和阈值是什么？
- 一致性与可用性冲突时，取舍原则是什么？
